# Public scientific evidence

`panels/` contains fixed natural, equal-law, neutral-prefix, re-rendering and
state-interchange arrays. Its manifest records their seeds and array hashes.
`gate_A/` supplies the frozen name resolver and its exact held-out audit.
`bulk/` contains the numerical reports, trained checkpoints, exposures and
saved-state analyses required by the six distributed studies.

`public/` contains public projections built by the ledger script. Each projection
is hash-bound to the corresponding distributed scientific artifact. Projections
are not transcripts and contain no private interpretation attachments.

`identity_projections.json` binds historical metadata hashes to their portable
scientific versions. Path substitutions, standalone specifications, dependency
extraction and serialization of metadata change hashes, not measured counts or
model tensors. A saved checkpoint can retain its historical registration hash;
loading accepts only an explicit chain in this file, never an unknown identity.
The registered numerical settings, data splits and training endpoints are
retained. The retained parent is audited on all 1,555 histories when loaded.

The two historical registration identities retained by immutable checkpoints are
`e9e95f9e44b3ad63e44ff39010f795d27f0b731133228adff30ccc7d3227f510`
(r8) and `32d7590ab29148d6ce60bc9e5612bfeb03695d76f96d02344ac8288f210fe926`
(r12). Their public registrations replace internal attachments with the
standalone `specification.md` files and use portable data/source identities.

Scientific analysis specifications beside each study retain the independent
calibration criteria and recorded auxiliary facts used by reporting. They do
not add observations or change a registered numerical threshold.
